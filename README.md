# Trade Workspace

Orange operations workspace for shipment and customs workflows. Fictional sample records; changes last only for the current browser session. No live customs services are connected.

Features include a priority workbench, personal and exception views, record previews, assignment, bulk completeness checks, reusable templates, field-level corrections, documents, history, reports and CSV export.

## Development

Run `npm ci`, `npm run dev`, `npm test` and `npm run build`. The static build is in `dist/`. Relative asset paths and hash routes support GitHub Pages project URLs.

## Hosting

The GitHub Actions workflow builds and deploys the static app to GitHub Pages. Set the repository Pages source to GitHub Actions.
